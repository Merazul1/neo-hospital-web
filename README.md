## 🚀 Key Features

* **Dual-Intent Emergency & Elective UX:** Instant 1-tap dial to 24/7 Helpline `9919722223`, ambulance dispatch, and streamlined OPD appointment booking.
* **Streamlined Executive Navigation:** Brand identity locked with `shrink-0` to eliminate overlap, with a categorized two-column mega-dropdown for facilities.
* **Interactive Appointment & Bed Inquiry Modal:** Direct routing to hospital WhatsApp (`+91-9919722223`) with auto-generated patient slip.
* **Cashless TPA & Mediclaim Hub:** Empanelled with major private health insurers (Star Health, ICICI Lombard, HDFC ERGO, Care Health, Niva Bupa) and Ayushman Bharat guidance.
* **North Lucknow Local Catchment Silos:** Dedicated navigation cues for Tedhi Pulia Chauraha, Ring Road, Aliganj, Jankipuram, and Vikas Nagar.
* **Full Structured Data (JSON-LD):**
  * `Hospital` / `MedicalBusiness` / `EmergencyService`
  * `MedicalProcedure` (Chemotherapy, Joint Replacement, Laparoscopy, NICU)
  * `FAQPage` Schema for Google rich search results

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Merazul1/neo-hospital-web.git
cd neo-hospital-web
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
Production assets are generated in `dist/`.
